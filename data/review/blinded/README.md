# Blinded review package (MAPS v2.1, draft)

Each `items/rv-*.json` is one scenario under an opaque id; its evidence copy is `evidence/ev-*.md`. Truth labels are intentionally absent. For each item judge, using only this package: (1) does the evidence document support or contradict the claim; (2) can each root's method measure the exact quantity defined; (3) are the four roots genuinely independent, beyond differing ids; (4) is the shared-factor list complete; (5) any ambiguity or unintended clue. Record answers in `reviewer_form`. Do not open the answer key until all items are reviewed.
